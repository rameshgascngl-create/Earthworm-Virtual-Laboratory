# Historical extraction evidence — not acceptance results

These files were produced during earlier passes using an approximate standalone SVG export. The export did not preserve every browser CSS behavior and manually reconstructed some transforms.

Claims that these proofs established the absence of live-app collisions, confirmed a broken respiratory rectangle, or proved weak/broken anatomy rendering are withdrawn. The old geometry numbers are only measurements of those exports.

They are retained for traceability, not as evidence that 1.3.3-beta has passed browser/mobile rendering. Consult the current AUDIT.md and execute the full-page browser suite before making new visual-defect claims.

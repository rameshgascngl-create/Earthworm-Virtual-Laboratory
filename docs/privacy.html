Overview

Earthworm Virtual Laboratory is an offline educational application for undergraduate Zoology teaching. The app works without an account, advertising, analytics, or remote data collection.

Information collected

The app does not ask for or collect a student’s name, email address, phone number, location, contacts, camera data, microphone recordings, photos, files, or advertising identifier.

The Android application requests no INTERNET permission and includes no advertising or analytics SDK.

Information stored on the device

The app may store language preference, guided-learning progress, assessment progress and scores, and review dates locally on the device. This information is not transmitted by the app. Android cloud backup is disabled.

Speech

Narration uses an Android text-to-speech voice installed on the device. The application does not send narration text to an online speech service.

Printing

Print / Save opens the Android print service selected by the user.

External reference links

Scientific reference links open only after a user action in the device browser. The app itself does not load remote web content.

Advertising and analytics

The app contains no advertising SDK and no analytics SDK.

Children’s privacy

The app does not create user accounts and does not knowingly collect personal information from children or students.

Security and retention

Local data remains on the device until the app data is cleared or the application is uninstalled.

Changes to this policy

If a future release changes permissions, network behaviour, analytics, accounts or data handling, this policy will be updated before that release is distributed.

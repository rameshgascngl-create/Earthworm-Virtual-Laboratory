# Privacy and data handling — beta source

The bundled simulator stores language preferences, guided progress, quiz results and review dates locally on the device. It does not request a student name, account, camera, microphone or location. The Android package requests no internet or storage permission and includes no analytics or advertising SDK.

Speech uses an installed voice marked by the Android TTS engine as not requiring a network connection. Voice availability and quality depend on the installed engine. The app does not send narration to an online speech API.

Reference links open the user's browser after a tap; the external website and browser apply their own data practices. Printing opens the Android print service, where the user chooses a printer or Save as PDF destination.

Progress remains until the app's data is cleared or the app is uninstalled. Android cloud backup is disabled. This draft describes the supplied source and must be rechecked against the actual signed release and its dependencies before a Play listing is submitted.

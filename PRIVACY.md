# Earthworm Virtual Laboratory — Privacy Policy

**Effective date:** 22 September 2026  
**App:** Earthworm Virtual Laboratory  
**Android package:** `in.ramesh.zoology.earthwormlab`  
**Developer:** Department of Zoology, Government Arts and Science College, Nagercoil

Earthworm Virtual Laboratory is an offline educational Android application for learning earthworm anatomy, guided dissection, revision and assessment.

## Information collected

The app does **not** require an account and does not collect or request a student's name, email address, phone number, contacts, precise location, camera images, microphone audio, files or advertising identifiers.

The Android app requests no INTERNET, camera, microphone, storage or location permission. The release contains no advertising SDK and no analytics SDK.

## Information stored on the device

The app may store the following educational state locally on the device:

- language preference;
- guided-study and dissection progress;
- assessment results;
- review dates and revision progress;
- selected offline text-to-speech preferences.

This information remains inside the app's local WebView storage. Android cloud backup is disabled. Local app data remains until the user clears app data or uninstalls the app.

## Speech

Narration uses an Android text-to-speech voice installed on the user's device. The app selects voices that are marked as not requiring a network connection. The app does not send narration text to an online speech service.

## External links

The app itself operates without Internet permission. When the user deliberately opens a scientific reference or the public Privacy Policy, Android opens the link in the user's external web browser. The destination website and browser are governed by their own privacy practices.

## Printing

The Print / Save feature invokes the Android print service. The user chooses the destination, such as a printer or Save as PDF. The app does not upload printed content to a developer-operated server.

## Children and students

The app is intended as an educational resource. Because it does not provide accounts, advertising, analytics or developer-operated network collection, it does not intentionally collect personal information from students or children.

## Security and data sharing

The app does not sell personal information and does not share personal information with advertisers or analytics providers. The application is configured with Android backup disabled and cleartext network traffic disabled.

## Changes to this policy

If a future version changes the app's permissions, data collection, analytics, advertising, account features or cloud services, this policy will be reviewed and updated before that version is distributed.

# Privacy Policy — Earthworm Virtual Laboratory

**Effective date:** 26 September 2026  
**App:** Earthworm Virtual Laboratory  
**Package:** `in.ramesh.zoology.earthwormlab`  
**Developer / Institution:** Department of Zoology, Government Arts and Science College, Nagercoil, Tamil Nadu, India  
**Contact:** rameshgascngl@gmail.com

## Overview

Earthworm Virtual Laboratory is an offline educational Android application for undergraduate Zoology teaching. The native application is designed to work without an account, advertising, analytics, or remote student-data collection.

## Information collected

The app does **not** ask for or collect a student's name, email address, phone number, location, contacts, camera data, microphone recordings, photos, files, or advertising identifier.

The Android application requests **no INTERNET permission** and includes no advertising or analytics SDK.

## Information stored on the device

The current native application stores only limited learning-state information in local Android app storage:

- the last opened anatomy system;
- identifiers of structures the learner has visited;
- the latest assessment score.

Guided-step position and the current Tamil/English mode are activity/session state and are not retained as long-term learning records after that activity/session ends.

Android cloud backup is disabled. Local app data normally remains until the user clears the app's data or uninstalls the application.

## Speech

Narration is attempted only with an Android text-to-speech voice that the installed TTS engine reports as **not requiring a network connection** for the selected language.

If no suitable offline voice is installed, the app does not start narration and instead informs the user that an offline voice is unavailable.

The app itself requests no INTERNET permission.

## External browser

The in-app **View public Privacy Policy** button can open this project's public policy page in the user's external web browser after a user action.

The Earthworm Virtual Laboratory application itself does not embed or load remote web content. Any data handling performed by the external browser or website is governed by that browser or website.

## Advertising and analytics

The app contains no advertising SDK and no analytics SDK. The developer does not sell student information to advertisers.

## Children's privacy

The app does not create user accounts and does not knowingly collect personal information from children or students. The limited learning state described above remains in local app storage.

## Security and retention

The native app is designed as an offline teaching resource. Local learning state remains on the device until app data is cleared or the application is uninstalled.

## Changes to this policy

If a future release changes permissions, network behaviour, analytics, account handling, or stored data, this policy will be updated before that release is distributed.

# Privacy Policy — Earthworm Virtual Laboratory

**Effective date:** 22 September 2026  
**App:** Earthworm Virtual Laboratory  
**Package:** `in.ramesh.zoology.earthwormlab`  
**Developer / Institution:** Department of Zoology, Government Arts and Science College, Nagercoil, Tamil Nadu, India  
**Contact:** rameshgascngl@gmail.com

## Overview

Earthworm Virtual Laboratory is an offline educational application for undergraduate Zoology teaching. The app is designed to work without an account, advertising, analytics, or remote data collection.

## Information collected

The app does **not** ask for or collect a student's name, email address, phone number, location, contacts, camera data, microphone recordings, photos, files, or advertising identifier.

The Android application requests **no INTERNET permission** and includes no advertising or analytics SDK.

## Information stored on the device

The app may store the following learning information locally on the user's device:

- language preference;
- guided-learning progress;
- assessment progress and scores;
- review dates and related study-state settings.

This information is stored locally so the learner can continue a study session later. It is not transmitted to the developer or college by the app.

Android cloud backup is disabled for this application. Local app data normally remains until the user clears the app's data or uninstalls the app.

## Speech

Narration uses an Android text-to-speech voice installed on the device. The app selects voices that Android reports as not requiring a network connection. The application does not send narration text to an online speech service.

## Printing

When the user chooses Print / Save, the app opens the Android print service. The user then selects a printer or Save as PDF destination. Any data handling by the selected print service is governed by that service.

## External reference links

Scientific reference links are opened only after a user action and are sent to the device's external web browser. The Earthworm Virtual Laboratory app itself does not load remote web content. External websites and the browser have their own privacy practices.

## Advertising and analytics

The app contains no advertising SDK and no analytics SDK. The developer does not sell or share student information with advertisers.

## Children's privacy

The app does not create user accounts and does not knowingly collect personal information from children or students. Learning progress remains on the device.

## Security and retention

The app is designed as an offline teaching resource with local-only progress storage. Data remains on the device until the app's data is cleared or the application is uninstalled.

## Changes to this policy

If a future release changes the permissions, network behaviour, analytics, account system, or data handling of the application, this policy will be updated before that release is distributed.
